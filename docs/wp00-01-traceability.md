## 2. 风险追踪（PLAN §19 共 22 项）

缓解措施与触发应对的完整原文见 PLAN §19，此处只补「首检门禁」与「停止动作」，用于门禁复核。

| ID | 风险 | 首检门禁 | 触发后的停止动作 |
|---|---|---|---|
| R-01 | 范围过大导致长期不可用 | G1、G3、G5 | 暂停新能力，完成当前闭环后重排 |
| R-02 | 个人开发者成为单点 | 全程 | 冻结发布，按文档移交，不做高风险变更 |
| R-03 | 多租户数据泄漏 | G2 | 停相关端点、保全证据、通知与修复 |
| R-04 | 权限模型过于复杂 | G2 | 收敛条件与模板，禁止手工例外扩散 |
| R-05 | 汇报线/兼岗/代管造成上下级权限错误 | G2 | 撤销相关范围、刷新缓存、审计历史访问 |
| R-06 | 部门沟通与文件权限不同步 | G3 | 停止外链、重建 ACL、审计并通知 |
| R-07 | 特殊启用被滥用形成影子系统 | G5 | 暂停该主管特殊启用权，老板集中复核 |
| R-08 | 模块数量膨胀拖垮个人开发 | G3、G5、G6 | 必须替换等量范围或重新估算 |
| R-09 | 低代码模式升级破坏数据 | G5、G6 | 阻断发布，要求显式迁移方案 |
| R-10 | HR/薪酬地域规则变化 | G7 | 退回独立项目，由法务与薪税专家参与 |
| R-11 | AI 越权或误执行 | G9 | 全局停写、撤销委托、审计回滚 |
| R-12 | 提示注入和知识污染 | G9 | 隔离来源、禁用工具组合、重评测 |
| R-13 | 插件破坏或供应链攻击 | G8 | 自动终止、禁用版本、通知安装租户 |
| R-14 | 外部集成不稳定或重复 | G8 | 断路、暂停连接、人工对账后恢复 |
| R-15 | PostgreSQL 动态数据性能 | G10（尖峰 B 前置） | 物化投影或报表库，再评估拆分 |

PLAN §20 的完整范围外清单未在此复述，避免两份清单漂移。任何将范围外事项转为承诺的动作，必须走 `docs/change-request-template.md` 并触发重新估算；不得由单个工作包自行吸收。
