## 0. 拆分口径

- 任务编号 `T<工作包>-<序号>`，粒度以「能独立产出并验收」为准。
- 每项任务给出：输入、动作、产出、验收证据、失败处理。
- 不含工时估算。顺序按依赖排列，不按日历排列。
- 任何任务若产出否定结论（尖峰失败），走「失败处理」，不得降级为「开发中再解决」。

## 3. WP00-03 六类技术尖峰

每个尖峰必须同时包含正向验证与**绕过尝试**，仅有正向不算通过。

| ID | 尖峰 | 通过标准 | 失败处理 | 产出 |
|---|---|---|---|---|
| T00-03-1 | A：PostgreSQL RLS 默认拒绝 | 缺失租户上下文、伪造 `tenant_id`、批量写、连接池复用四种场景全部被拒，且错误响应不泄露他租户数据 | 改为 schema-per-tenant 或物理隔离，重估 Phase 1–2 | 尖峰报告 + ADR |
| T00-03-2 | B：低代码动态字段与 10 万记录查询 | 类型化字段、关系、索引可用；10 万记录代表性查询有明确性能结论与索引方案 | 限制字段规模、引入物化视图，或推迟低代码到 P1 | 尖峰报告 + ADR |
| T00-03-3 | C：工作流幂等与补偿 | 重复回调、超时重试、并行任务、补偿重放四种情况下副作用各只发生一次 | 改为 outbox + 强制幂等键，重写工作流内核 | 尖峰报告 + ADR |
| T00-03-4 | D：插件执行器隔离 | 数据库直连、文件系统访问、未授权网络访问三类越界全部失败且留审计 | 降级为无插件能力，插件平台移出 GA 范围 | 尖峰报告 + ADR |
| T00-03-5 | E：AI 工具最小链路 | 工具注册、权限再检查、审批绑定、幂等、回执字段完整；越权与重复调用被拒 | AI 写操作推迟到 P1，GA 仅保留只读建议 | 尖峰报告 + ADR |
| T00-03-6 | F：Windows 工作助手 | 能在内容读取前识别微信/QQ 并本地过滤；Edge/Office/VS Code 适配可用；设备身份有效；主动语音转写可用 | 关闭对应采集能力，或整体推迟工作助手 | 尖峰报告 + ADR |

**外部依赖**：尖峰 B 需代表性数据生成器；尖峰 D 需隔离运行时；尖峰 F 需真实 Windows 终端、目标应用与麦克风。

## 7. 需要用户显式授权的动作

以下动作在任何情况下都不自动执行：

| 层级 | 动作 | 触发条件 |
|---|---|---|
| 立即允许 | 阅读文档、生成计划类文件、只读盘点环境 | 无需额外授权 |
| 需 G0 通过 | 创建仓库骨架、编写脚本、生成 ADR 与证据目录 | 用户确认进入实施 |
| 需逐项授权 | 安装 JDK/Maven/Node/pnpm/.NET/Docker/PostgreSQL、修改系统设置、占用端口 | 每项单独确认 |
| 需专项批准 | 采集真实员工数据、连接真实 HR 或模型供应商 | 另行评估与签署 |
