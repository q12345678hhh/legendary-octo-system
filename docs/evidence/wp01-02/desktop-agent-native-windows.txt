三、真实桌面采样（原生验收的关键一步）
--------------------------------------
命令     %TEMP%\wa-native-publish\WorkAssistant.PrivacyEngine.Checks.exe --live
实际
```
== 原生 Windows 验收 ==
OS        Microsoft Windows 10.0.26200
Runtime   .NET 8.0.33
Machine   YURI  User Administrator  Session 1
判定依据   进程名 + 窗口标题；未读取窗口内容

真实运行 Weixin 进程 5 个，全部按排除处理
真实运行 QQ 进程 12 个，全部按排除处理

采样可见窗口 17 个：标题关键字命中 0 个，未知进程 0 个，允许采集 15 个
进程级排除 17 个（判定在读取窗口内容之前完成）

检查通过 19 项，失败 0 项，窗口样本 17 个
真实命中: Weixin x5、QQ x12
LIVE_EXIT=0
```
结论     通过。采样对象是这台机器上真实运行的微信与 QQ，不是模拟快照：
         12 个 QQ 进程、5 个 Weixin 进程全部在读取窗口内容之前被排除，
         另有 15 个可见窗口按普通工作应用放行。

四、判定边界
------------
- 采样只用 Win32 EnumWindows / GetWindowText 取标题，用 Process.ProcessName 取进程名。
- 不读窗口正文、不进 UI Automation 控件树、不取剪贴板、不截屏。
- 判定失败即拒绝：进程名取不到时按排除处理（本次真实桌面样本中未出现）。
- 停止采集后采集量归零，采集提示随状态可见。

五、未覆盖项
------------
- Windows 工作助手的 UI 外壳（托盘、状态提示、语音）属于 Phase 4 范围，本期只验隐私边界与原生可运行。
- 只在 Windows 11 26200 单机上验证，未覆盖 Windows 10 与多显示器 / 高 DPI 场景。
