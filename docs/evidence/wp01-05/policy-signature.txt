# 客户端离线验签（来源：Device.Checks 离线自检）
PASS offline/策略进程为服务端追加项与本地硬编码下限的并集
PASS offline/策略关键字包含本地硬编码下限
PASS offline/策略关闭上传时采集量为 0
PASS offline/未注册时状态为未注册且策略版本为 0
PASS offline/合法策略验签通过
PASS offline/策略版本不前进时拒绝回滚
PASS offline/策略 key id 不匹配时拒绝
PASS offline/策略签名被篡改时拒绝
PASS offline/策略含未知字段时拒收
PASS offline/更新清单验签并暂存成功
PASS offline/健康检查失败时回滚到上一版本
PASS offline/更新清单 key id 不匹配时拒绝
