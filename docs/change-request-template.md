# 变更请求模板

| 项目 | 内容 |
|---|---|
| 任务 | T00-01-5 |
| 适用 | 任何新增范围、范围外转入、工期或验收口径变更 |
| 规则 | 不填齐六栏不得评审；未批准不得进入任何工作包 |

## 1. 六栏必填项

| 栏位 | 填写要求 |
|---|---|
| 1. 业务价值 | 说明为谁解决什么问题；说不出可量化收益的不进入评审 |
| 2. 影响模块 | 列出受影响的 PLAN 章节、后端模块、前端页面、契约与迁移 |
| 3. 数据与迁移 | 是否新增表或字段、是否需要回填、是否影响既有租户数据 |
| 4. 权限与安全影响 | 是否新增权限点、是否触及 C3 数据、是否改变租户边界或 AI 风险等级 |
| 5. 排期影响 | 替换哪些既有范围，或明确增加多少周；不允许「隐性加入」 |
| 6. 替代方案 | 至少给出不作变更、延后到 P1、缩减版本三种之一 |

```text

提出人：

变更类型：新增 / 修改 / 删除 / 范围外转入 / 工期调整

1. 业务价值：

2. 影响模块：

3. 数据与迁移：

4. 权限与安全影响：

5. 排期影响（替换项或增加周数）：

6. 替代方案：

评审结论：接受 / 有条件接受 / 拒绝 / 延后
条件：
批准人：              日期：
```

## 3. 裁决规则

| 情形 | 处理 |
|---|---|
| 触及租户边界、权限模型或 C3 数据 | 必须由安全隐私复核人参与，不得仅由计划批准人决定 |
| 触及薪酬或 HR 规则 | 必须由 HR/薪酬专家签字 |
| 增加范围但未替换等量范围 | 一律拒绝，按 PLAN §19 R-08 处理 |
| 工期变更 | 触发 G1/G3/G5 重估，不单独改日历 |
| 转入范围外事项 | 先补 PLAN 章节，再升版，再重新走 G0 |

## 4. 记录位置

已批准与已拒绝的变更单全部保留在 `docs/change-requests/` 目录，不删除、不覆盖。拒绝理由同样留档，用于后续复盘同类请求。
